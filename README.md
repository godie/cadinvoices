# CAD Invoices

A modern web application for creating and managing invoices with PDF generation capabilities.

## Features

- 📄 Create and manage invoices
- 📊 Service items table with automatic calculations
- 📥 PDF generation with professional formatting
- 💾 Draft saving with local storage persistence
- 🎨 Clean, responsive UI built with React

## Tech Stack

- **Framework:** React 19 with TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Form Handling:** TanStack Form with Zod validation
- **PDF Generation:** jsPDF with autoTable

## Getting Started

### Prerequisites

- Node.js 22+
- pnpm 10+

### Installation

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build

# Preview production build
pnpm preview
```

## Type Checking

```bash
pnpm tsc --noEmit
```
